# Trekking Management Application

A Flask-based Trekking Management System developed for the IIT Madras Modern Application Development-I course.

## Tech Stack

- Flask
- SQLAlchemy
- SQLite
- Flask-Login
- Bootstrap 5
- HTML/CSS

## Features

- Admin Dashboard
- Staff Dashboard
- User Dashboard
- Trek Management
- Trek Booking
- Booking History
- Role-Based Authentication
